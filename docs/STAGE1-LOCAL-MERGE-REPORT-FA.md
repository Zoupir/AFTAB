# گزارش مرحله ۱ | ادغام محلی AFTAB

**وضعیت: ادغام محلی انجام شده؛ ادغام در GitHub و CI هنوز انجام نشده‌اند.**

سورس مبنا: فایل ZIP بارگذاری‌شده توسط کاربر `AFTAB-next-orchestration-v1.zip` که برچسب مرجع در فایل ZIP آن `7ccb9fc66157f77c8b0f1f60b56dc72e4bef1fc9` است. این یک فایل فشرده از شاخه است، نه checkout حاوی تاریخچه Git. برای اجرای ابزار ادغام، یک Git repository موقت و محلی از روی این ZIP ساخته شده است. برچسب SHA در فایل ZIP به‌تنهایی اثبات نمی‌کند که شاخه آنلاین فعلی هنوز همان نسخه است.

## تغییرات اعمال‌شده

- لایه محاسبه مصرف، ذخیره اتمیک نمونه‌های ترافیک و انتقال وضعیت در SQLite
- خواندن آمار Xray با StatsService بدون صفرکردن شمارنده‌ها
- رابط Agent برای آمار و شناسایی کاربران و بررسی حذف/افزودن
- بازیابی کاربران معتبر پس از ری‌استارت و توقف در برخورد هویت
- کنترل تنظیمات اولیه API، StatsService و policy پیش از راه‌اندازی Agent
- همگام‌سازی دوره‌ای در پنل با قفل در برابر عملیات مدیریتی هم‌زمان
- تست‌های اضافه‌شده و اجرای ۱۲ تست ایمنی ابزار ادغام

## آزمون‌های واقعاً اجراشده در این محیط

- `python3 -m unittest discover -s tools -p test_apply_to_aftab.py -v` → **۱۲ از ۱۲ موفق**
- `go test -race -mod=mod -count=1` بر بسته‌های internal/metering، provisioning، nodeconfig، agenthttp، subscription، awgprofiles، frame، observability و dashboard → **موفق**
- تست کامل `go test ./...` → **اجرا شد اما تکمیل نشد**: `go.sum` و بسته‌های خارجی Go در محیط محلی وجود ندارند و DNS/دریافت از proxy.golang.org غیرفعال است.
- اجرای GitHub Actions بر روی نسخه ادغام‌شده → **انجام نشده** چون اتصال ابزار GitHub در این مکالمه خطای داخلی دارد.
- تست واقعی اتصال سیستم شمارش حجم به Xray زنده و قطع کاربر → **انجام نشده**.

## محدودیت‌ها و یادداشت امنیتی

این خروجی برای بازبینی و CI است، نه نصب مستقیم روی VPS. پیش از استقرار باید تست گره Xray واقعی با تولید مصرف غیرصفر، ری‌استارت، و ابطال کاربر انجام شود. بسته کامل سورس جایگزین commit یا release نهایی نیست. فایل Patch را فقط روی نسخه دقیق سورس مبنا اعمال کنید و ابتدا `git apply --check` را اجرا کنید. اگر سورس آنلاین تغییر کرده باشد، ادغام باید بازبینی شود.

**از سمت این عملیات هیچ دسترسی یا تغییری روی VPS و 3x-ui انجام نشده است.**
